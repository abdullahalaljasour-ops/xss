🛡️ منصة المحاكاة السيبرانية المتقدمة (Cyber Range)

إعداد وتطوير: المهندس عبدالله بن جريد — مهندس وأخصائي أمن سيبراني

التحديات المكتملة: 0 / 11

1. تحدي حقن قواعد البيانات (SQL Injection - Auth Bypass)

الهدف: تجاوز نموذج تسجيل الدخول كمسؤول admin عبر التلاعب بمنطق الاستعلام.

مراقب الاستعلام (Backend Query)

SELECT * FROM users WHERE username = '' AND password = '';

2. تحدي البرمجة عبر المواقع (Cross-Site Scripting - XSS)

الهدف: حقن كود JavaScript لتنفيذ أمر منبثق وسرقة الجلسة الوهمية.

Session: SESSION_ID=ABJ_SECURE_99
النتيجة المعروضة: فارغ

تحليل DOM

element.innerHTML = userInput; // مصاب
element.textContent = userInput; // آمن

3. تجاوز الصلاحيات المباشر (IDOR)

الهدف: تعديل رقم المعرف في الرابط للوصول إلى ملف المدير رقم 101.

{ "id": 104, "role": "Student" }

4. تصعيد الصلاحيات عبر التوكن (JWT Tampering)

الهدف: تعديل حمولة توكن الجلسة من دور مستخدم عادي "role":"user" إلى "role":"admin".

5. حقن أوامر النظام (OS Command Injection)

الهدف: استغلال أداة فحص الشبكة عبر إرفاق أمر إضافي مثل ; cat /etc/passwd.

بانتظار المدخلات...

6. اجتياز المسارات (Directory / Path Traversal)

الهدف: قراءة ملف النظام الحساس عبر الهروب من المجلد الرئيسي باستخدام ../../.

الملف فارغ

7. تزوير الطلبات عبر المواقع (CSRF)

الهدف: محاكاة صفحة خبيثة تُرسل طلباً خفياً لتغيير البريد الإلكتروني للمستخدم دون علمه.

8. رفع الملفات غير المقيد (Unrestricted File Upload)

الهدف: محاولة رفع ملف تنفيذي خبيث بصيغة webshell.php بدلاً من صورة صالحة.

9. الثغرات المنطقية للتجارة الإلكترونية (Business Logic)

الهدف: التلاعب بكمية المنتجات في سلة التسوق بإدخال قيمة سالبة للحصول على رصيد مجاني.

الإجمالي: 100 ريال

10. ضعف التشفير والتجزئة (Weak Hashing)

الهدف: التعرف على خطر استخدام خوارزميات قديمة مثل MD5 واستخدام جداول التكسير (Rainbow Tables).

11. تحليل سجلات حوادث الأمان (SOC Log Analysis)

الهدف: فحص السجلات التالية ومعرفة عنوان IP الخاص بالمهاجم الذي نفذ هجوم المسح.

192.168.1.10 - GET /index.php 200
192.168.1.45 - POST /login.php 302
